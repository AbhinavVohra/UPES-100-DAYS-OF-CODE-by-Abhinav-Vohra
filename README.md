# UPES-100-DAYS-OF-CODE-by-Abhinav-Vohra

DESCRIPTION : The following repository contains C programs as provided by my university through a challenge staying for about 3 months(100 days).
This challenge provides 2 questions per day for the first 50 days and 1 question and 1 question per day for the later 50 days making a total of 
150 questions throughout the challenge. These questions target the syllabus of the whole first semester,s C programming.
Assistance of Google,AI(Chatgpt) has been taken in cases where the questions were ahead of the knowledge I had.
But throughout the assignment/challenge my aim was to learn as many varieties of questions as I can within the syllabus of this semester and more
if I can.

Note : The programs were committed to this github repository using github itself(no gitbash or vs code was used till now-26th October 2026). However 
, the file was never uploaded from an existing media(from the memory/storage of the laptop/pc) instead were committed to in the repository after completing them in github itself.

For further verification and Error Handling : https://www.onlinegdb.com/online_c_compiler and Vscode were used as a medium.

This repository only has a single contributor which is me and features no collaboration with any other members.
